# Known issues

**The verdict.** No known issue lets anyone move held funds outside a deal's signed terms on the deployed phase-one contracts [inferred: Crow's own reviews and the triage of an outside scan, each read against the code at the tag]. Each harm this page records stays within one deal: its price and fee decided wrongly by an adjudicator the parties named, the buyer's key published by a call that then reverts, or a deal that waits for its timeouts. The few small code defects in part 1 are fixed in the next contract build. Every other row is a design limit a party accepts by signing (part 2), an item in the off-chain code (part 3), or history (part 4). No external audit has run (G-6), and nothing on this page says the contracts are secure. Crow runs on Ethereum Sepolia with test tokens only, so no row puts real money at risk today.

This page is the list an auditor reads. It describes the phase-one contracts at the frozen commit, the annotated tag `contracts-phase-one-1`, whose `contracts/src` equals the deployment record's `commit` ([`scope.md`](scope.md)). They are deployed on Sepolia since 2026-11-13. Phase one has no party appeals and no bonds (D57); the rows about them are in appendix C. SimChain keeps both as the full protocol's reference, and the contracts deployed on 2026-11-04 (domain 0.7) keep them for the deals opened on them. Scope is in [`scope.md`](scope.md).

How to read it:
- **Severity** is the word the source uses; where sources differ, the row gives each. "Not rated" means the source gives none.
- **Status** is one of: open, accepted, fixed in a PR, deferred to a task, not in phase one.
- Every row is documented in the file its "Recorded in" column names. A row says [inferred] where this page concludes something the source does not state.
- Rows marked **OS-** come from an outside scan of the five files of `contracts/src/` at the tag, triaged on 2026-11-18 (T-523). They are the scan's confirmed findings; the scan's other findings were already on this page or in the reviews it cites.
- T-212, the contract hardening task, is paused. At the tag `contracts-phase-one-1`, its items L-4, L-6, L-8 and I-2 are fixed, and L-2 and L-5 are not in phase one (appendix C). The 2026-11-04 contracts keep every item for the deals opened on them ([T-212](../tasks/T-212-contract-hardening.md), Status).

## Appendix A. Testnet-only facts

- **tUSDC is open-mint.** Anyone can mint any amount; it guards no value (`contracts/script/TestUSDC.sol`).
- **The relayer pays test ETH.** One Sepolia-only relayer secret on operator node 1 pays gas through a funding lane and three deal lanes. It has no role in any contract (`docs/operations.md`, Secrets).
- **The demo adjudicators' keys are generated in a Durable Object.** The world derives the three adjudicators' keys, both operators' keys and the club's keys from one random secret that it creates and stores (`apps/demo-cloud/src/world.ts`, `meta.secret`). Crow therefore runs the primary, fallback and appeal adjudicators of the demo.
- **Both operator nodes serve one world.** Node 2 has its own receipt key and forwards to the same Durable Object (`docs/operations.md`, "What is live").
- **Live judges are capped at 30 calls a day.** Past the cap, panels are scripted and every verdict says so. The DeepSeek model IDs are provider aliases with no dated snapshot (`config/judges-live.yaml`).
- **The deployer is a throwaway key** with no authority on chain.
